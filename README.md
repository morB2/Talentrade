## About The Project

**TalentTrade** is a social network platform where users can exchange goods and services, either for money or for other services. The platform is built around a category-based system where users can post service offers or requests, with a rich commenting and interaction system.

Key Features:
* Users can post service offers or requests and receive comments with offers.
* Service owners can approve comments they are interested in.
* Ability to edit, delete, and close services.
* Users can like comments, and those who received a service can rate the provider.
* Three user types: regular user, guest (read-only), and admin (who can delete users and view reports).
* JWT authentication ensures secure access.
